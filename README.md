# 📐 CAD Map Navigator (듀얼 모드: 순수 캐드 뷰어 + 현장 지도 GPS 길찾기)

오토캐드(AutoCAD) 도면(`.dxf`)을 사무실과 현장 어디서든 자유롭게 활용할 수 있도록 **[순수 CAD 뷰어]**와 **[현장 지도/GPS 네비게이션]**을 완벽하게 통합한 올인원 PWA 웹 애플리케이션입니다.

---

## 🌟 듀얼 모드 (Dual Mode) 소개

화면 상단의 탭 버튼 하나로 1초 만에 모드를 전환하며 도면 데이터를 공유합니다:

### 1. 📐 순수 CAD 뷰어 모드 (사무실 / 도면 정밀 검토)
- **오토캐드 스타일 다크 캔버스**: 렉 없는 고성능 2D HTML5 Canvas 기반 구동
- **좌표계가 없는 도면도 완벽 지원**: 상세도, 단면도, 배근도, 설비도 등 지리좌표가 없는 일반 도면도 100% 검토 가능
- **정밀 치수 측정 도구 (📏)**: 도면 상의 두 점을 터치하여 2D 거리 및 $\Delta X, \Delta Y$ 실시간 측정
- **정점(Vertex) 자동 스냅 & 좌표 확인**: 마우스나 터치 위치의 실시간 CAD 좌표($X, Y$) 확인
- **"지도에서 이 위치 찾아가기 (🎯)" 원클릭 연동**:
  - 도면 위의 특정 모서리, 말목, 맨홀을 터치하고 **[지도에서 이 위치 찾아가기]**를 누르면, 즉시 **현장 지도 모드로 자동 전환되면서 해당 지점으로 GPS 길안내가 시작**됩니다!

### 2. 🛰️ 현장 지도 / GPS 네비게이션 모드 (현장 실측 / 길찾기)
- **VWorld 고해상도 항공사진(위성) 및 일반지도 중첩**
- **다중 도면 레이어 중첩(Stack)**: 지적도 + 배관도 + 건축배치도를 한 번에 엎어보고 도면별 색상 구분
- **스마트폰 GPS & 3D 나침반 현장 유도**: 폰을 들고 회전하면 가야 할 방향을 실시간 3D 화살표로 안내 (10m 근접 및 2.5m 도착 진동 알림)
- **국내 표준 좌표계 (EPSG:5186, 5174, 5179 등) 및 2점 기준점 보정** 지원

1. **국내 고해상도 위성지도 및 일반지도 중첩**
   - **VWorld 항공사진(위성)**: 국토지리정보원 정밀 항공사진 지원
   - **VWorld 지명/도로명 하이브리드 라벨**: 도로명, 지번, 건물명 오버레이
   - **VWorld 2D 일반지도**: 산뜻한 벡터 배경지도
   - **Esri World Imagery & OpenStreetMap**: 해외/글로벌 위성 및 오픈 지도 지원

2. **국내 측량/지적 표준 좌표계 완벽 지원**
   - **EPSG:5186**: 한국 중부원점 (GRS80 / 2010 - 표준)
   - **EPSG:5185**: 한국 서부원점 (GRS80 / 2010)
   - **EPSG:5187**: 한국 동부원점 (GRS80 / 2010)
   - **EPSG:5188**: 한국 동해원점 (GRS80 / 울릉도/독도)
   - **EPSG:5174**: 한국 구 중부원점 (Bessel 1841 - 과거 지적도/구 도면)
   - **EPSG:5179**: UTM-K (네이버/카카오/국토정보 표준)
   - **도면 단위 자동 감지**: 미터(m) 및 밀리미터(mm) 도면 자동 스케일 감지 및 수동 전환

3. **현장 상대좌표(0,0) 2점 기준점 보정 (Helmert 2D Affine Transformation)**
   - 국가좌표계가 아닌 현장 임의(0, 0) 좌표로 그려진 도면도 OK!
   - 도면 상 2개 기준점(A, B)과 실제 지도의 2개 지점(A', B' 또는 내 현재 GPS)을 지정하면 축척, 회전각, 이동량을 자동 계산하여 지도 위 정확한 위치에 안착시킵니다.

4. **스마트폰 실시간 GPS & 3D 나침반 현장 길안내 (Navigation HUD)**
   - **원터치 목표점 지정**: 도면 상의 모서리, 측점, 배관 맨홀, 선분을 터치하면 바로 목표지점으로 등록
   - **실시간 남은 거리 표시**: 하버사인 기반 정밀 거리 측정 (예: `14.2 m`)
   - **실시간 3D 나침반 유도 화살표**: 폰의 내장 나침반(DeviceOrientation)과 연동되어 폰을 돌리면 목표가 있는 방향을 실시간으로 직관적으로 가리킴
   - **접근/도착 알림**: 10m 이내 접근 경고 및 2.5m 이내 도착 시 진동(`Vibration API`) 및 완료 배지 표시
   - **GPS 정밀도 모니터링**: 현장 GPS 수신 오차 범위(±2.5m 등) 실시간 표시

5. **도면 시각화 및 제어 도구**
   - **도면 투명도 조절**: 슬라이더로 10% ~ 100% 실시간 조절하여 항공사진과 도면을 겹쳐 비교
   - **고대비 야외 시인성 모드**: 햇빛이 강한 야외 현장에서도 도면이 뚜렷하게 보이도록 형광 노랑 고대비 모드 원클릭 전환
   - **레이어(Layer) On/Off 관리**: 건축선, 경계선, 배관, 텍스트 등 원하는 레이어만 선택 표시

6. **모의 주행 / 시뮬레이션 모드 (🎮)**
   - 현장에 나가기 전 사무실에서 PC/폰으로 지도를 클릭하여 가상 GPS 위치를 이동시키며 길안내 기능을 미리 시뮬레이션 가능

7. **체험용 샘플 도면 원클릭 로드**
   - 당장 캐드 파일이 없어도 상단 `🏛️ 샘플` 버튼을 누르면 서울시청 광장 부지 샘플 도면(기준점, 건물, 관로, 맨홀)이 즉시 로드됩니다.

## 🚀 실행 및 접속 방법

### 1. 간편 로컬 서버 실행 (PC에서)
프로젝트 폴더에서 포함된 Python 서버를 실행합니다:

```bash
cd c:\Users\slkam\Documents\cad-map-navigator
python serve.py
```

실행하면 터미널에 접속 주소가 표시됩니다:
- **PC 브라우저**: `http://localhost:8080`
- **스마트폰 접속**: `http://[PC의 IP주소]:8080` (예: `http://192.168.0.15:8080`)

### 2. 스마트폰에서 접속 및 앱처럼 홈 화면에 추가 (PWA)
1. 스마트폰을 PC와 **동일한 Wi-Fi(공유기)**에 연결합니다.
2. 스마트폰 웹 브라우저(크롬 또는 사파리)를 켜고 터미널에 뜬 주소(`http://192.168.x.x:8080`)를 입력합니다.
3. **앱으로 설치**:
   - **안드로이드 크롬**: 브라우저 우측 상단 메뉴(⋮) -> **[홈 화면에 추가]** 또는 **[앱 설치]** 선택
   - **아이폰 사파리**: 브라우저 하단 공유 버튼(네모+화살표) -> **[홈 화면에 추가]** 선택
4. 이제 홈 화면에서 앱 아이콘을 터치하면 상단 주소창 없이 전체 화면 앱으로 쾌적하게 실행됩니다!

## 📁 오토캐드(AutoCAD)에서 도면 저장 방법

본 앱은 보안상 사용자의 설계 도면을 외부 서버로 전송하지 않고 사용자의 브라우저 메모리 안에서 100% 로컬로 파싱 및 렌더링합니다.

1. 오토캐드(AutoCAD, ZWCAD, GstarCAD 등)에서 도면을 엽니다.
2. 상단 메뉴에서 **[다른 이름으로 저장 (Save As)]**을 클릭합니다.
3. 파일 형식을 **`AutoCAD 2018 DXF (*.dxf)`** 또는 **`AutoCAD 2000 DXF (*.dxf)`**로 선택하고 저장합니다.
4. 스마트폰이나 PC의 본 앱에서 **[📁 DXF 열기]** 버튼을 눌러 해당 파일을 선택하면 즉시 지도 위에 오버레이됩니다.

## 💡 현장 활용 가이드

- **경계점/말목 찾기**: 지적도나 부지 경계선 DXF를 불러온 후, 모서리 점을 탭하여 목표로 지정하고 나침반 화살표와 남은 거리를 보며 걸어가면 정확한 위치를 찾을 수 있습니다.
- **매설 배관/맨홀 위치 파악**: 지하 배관도면을 불러오고 도면 투명도를 조절하면 현재 지상의 어느 건물/도로 밑으로 관로가 지나가는지 직관적으로 비교할 수 있습니다.
- **GPS 정확도 팁**: 건물 내부나 숲 아래보다는 하늘이 트인 야외에서 스마트폰 GPS 정확도가 가장 높게(±2~3m) 측정됩니다.
